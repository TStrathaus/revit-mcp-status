Versions of the setup

A model is built with a setup: the scan2revit version (scan2revit/pyproject.toml), the git commit, the Revit version, pyRevit, and the template project. The setup's id is <version>-<commit> (with +dev when changed files were not committed), and it is part of every model's file name: <project>_v<setup>_<info>.rvt. When the setup gets better, a project is built again and gets a new file next to the old one; the Builds page lists every build with its setup.

Rules: the version goes up when what a build produces changes (a new element kind, a new route, a changed modelling rule: minor, 0.x); fixes keep the version and are told apart by the commit. Every version gets a row here when it is set, with what changed for the models.
